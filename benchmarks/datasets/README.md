# Public synthetic benchmark dataset

Eight fixtures are generated by `python3 benchmarks/datasets/generate.py` with Pillow 10.2.0. All text is fictional and contains no personal data. The six PNGs contain printed text or plain expressions; they do **not** measure real handwriting recognition accuracy. The one-page PDF contains the first synthetic page; the two-page PDF adds a second synthetic page. Both use official PaddleX `fileType: 0`. Both PDFs are in the `documents` scenario only, not the default baseline.

`manifest.json` records each sample's ID, type, pixel dimensions, byte size, page count, category, SHA256, source, and license. The files and generation script are MIT licensed as part of this repository. Rendered typefaces are DejaVu Sans (DejaVu fonts license) and AR PL UMing (Arphic Public License). Font files are not bundled. PDF metadata timestamps are fixed so regeneration with the documented Pillow and fonts is byte-for-byte reproducible. Other Pillow/font versions can change raster bytes; treat the checked-in SHA256 values as the exact dataset version for comparisons.

Private images may be supplied with `--images /local/path`; they and reports remain local. Do not publish reports containing private filenames or OCR responses without reviewing them. Different document categories are reported separately.
